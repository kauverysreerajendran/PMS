# StayHub Login Frontend

Frontend-only recreation of the supplied hotel-management login reference.

## Run in VS Code
1. Open this folder in VS Code.
2. Open Terminal.
3. Run `npm install`
4. Run `npm run dev`
5. Open the localhost URL shown by Vite.

## Stack
- React 19 + Vite
- TypeScript
- React Router DOM
- Axios
- Lucide React icons
- Responsive CSS

The login and Google buttons are UI-only. Connect them to your backend later in `src/lib/api.ts`.
